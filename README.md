# DWBuilder-HissoriAI
AIで作成した個人用のがばがばのだんウィズのビルドシミュレーターです。ご容赦。
間違っても本家様に問い合わせとかしないでね。

## バージョン管理

アプリの表示バージョンは `app-version.js` の `APP_VERSION` を変更します。現在は `ver0.3` です。編成画面とモンスター編集画面はこの共通値を表示します。ゲームデータの `game_version` やスキーマ版とは別に管理してください。

## データ

全ランクのモンスターデータは `data/monsters.json` と `data/parts.json` に新スキーマで統合し、語彙は `data/tags_registry.json` で管理します。旧ランク別JavaScriptデータは `old/` に保管しています。`index.html` と `monster-editor.html` は `data/` を読み込むため、`file://` ではなくローカルWebサーバーまたはWebサイト経由で開いてください。

編集画面の保存内容はブラウザーのローカルストレージに保存されます。JSONファイルとして共有する場合はエクスポートを利用してください。

編集画面の通常入力では、支配力ボーナスはパーツの `control_cost_bonus`、能力値ボーナスとダイスダメージは `structured`、効果テキストとタグは `raw` に保存されます。`raw.original_fields` は旧データの記録として詳細欄に保持され、通常入力とは同期しません。

モンスターIDは `rankX_通番_英語名`（例: `rank9_01_behemoth`）形式です。編集画面で新規登録すると、英語名を入力してIDを自動採番します。パーツIDはモンスターIDに `_M`、`_S1`、`_S2` を付けます。
