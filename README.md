# DWBuilder-HissoriAI
AIで作成した個人用のがばがばのだんウィズのビルドシミュレーターです。ご容赦。
間違っても本家様に問い合わせとかしないでね。

## バージョン管理

アプリの表示バージョンは `app-version.js` の `APP_VERSION` を変更します。現在は `ver0.3.1` です。編成画面とモンスター編集画面はこの共通値を表示します。ゲームデータの `game_version` やスキーマ版とは別に管理してください。

## データ

全ランクのモンスターデータは `data/monsters.json` と `data/parts.json` に新スキーマで統合し、語彙は `data/tags_registry.json` で管理します。旧ランク別JavaScriptデータは `old/` に保管しています。`index.html` と `monster-editor.html` は `data/` を読み込むため、`file://` ではなくローカルWebサーバーまたはWebサイト経由で開いてください。

編集画面の保存内容はブラウザーのローカルストレージに保存されます。JSONファイルとして共有する場合はエクスポートを利用してください。

編集画面の「最新データを反映」は、配信元の `data/monsters.json`・`data/parts.json`・`data/tags_registry.json` をキャッシュを避けて取得します。反映前にバックアップを出力し、等級5〜9を最新マスターに置き換えます。等級1〜4と独自語彙は保持します。

編集画面の通常入力では、支配力ボーナスはパーツの `control_cost_bonus`、能力値ボーナスとダイスダメージは `structured`、効果テキストとタグは `raw` に保存されます。`raw.original_fields` は旧データの記録として詳細欄に保持され、通常入力とは同期しません。

編集画面のカスタムタグは、公式タグの `raw.wiki_tags` とは別に、能力・パーツの `custom_tags` に保存されます。1行に1つ入力し、公式タグにない基準などを補足できます。保存・エクスポートの対象ですが、「最新データを反映」で置き換えられる等級5〜9のカスタムタグも他のローカル編集と同様に置き換わります。

パーツ選択画面では、等級・タグ・キーワードを組み合わせて絞り込めます。タグの候補は選択中のパーツ種別に登録されている公式タグとカスタムタグから作成され、選んだタグと完全一致するパーツを表示します。キーワードはパーツ名、タグ、効果テキスト、効果やダメージの内容を部分一致で検索します。英字の大文字・小文字と全角・半角は区別しません。基準能力は推定表示せず、登録されているタグだけを表示・検索します。

モンスターIDは `rankX_通番_英語名`（例: `rank9_01_behemoth`）形式です。編集画面で新規登録すると、英語名を入力してIDを自動採番します。パーツIDはモンスターIDに `_M`、`_S1`、`_S2` を付けます。
