- 調査日: 2026-11-08 (第2版: 公式パッチノート精査を反映)
- 対象バージョン: 最新は **v0.7.2 Build 217**。本文の詳細データは主に v0.6.3 Wiki 時点、計算式の多くは v0.3.2 攻略記事由来 — **バージョン差異に注意(§0参照)**

## 0. バージョン別戦闘システム変更史 (公式リリースノート精査)

出典: GameCoaster公式 [Release Note (JP)](https://gamecoaster.notion.site/Release-Note-JP-32e4966ac9c3801e92d7f4e6d00462bb)。**戦闘システムはバージョンで大きく変わるため、シミュレーションツールは対象バージョンを明示して実装すること。**

### v0.5.0 (Build 182, 2026年7月頃) — 9等級・5×5拡張・伝播/解体の変更
- **敵は待機せず交戦に即座に参加**するように(1交戦により多くのキャラが参加可)。※後にv0.5.4で一部撤回
- 施設の基本耐久度が **3→6** に増加
- **魔王の能力値伝播が変更**: モンスターと魔王の修正値のうち低い方は**半分のみ**適用
- 権能ダメージに魔王の主能力値ボーナスが適用。**権能の基本DCが12に統一**。ラグナロク等はセーブ成功時のダメージ減少
- 解体確率が大幅増加: 主要パーツ 基本6%→18% / 最大記憶段階24%→48%。補助パーツ 基本10%→30% / 最大50%→90%
- 9等級モンスター(合成のみ)、ダンジョン最大5×5、試練上限30、ステージ1〜4の敵HP・能力値減少

### v0.5.4 (Build 188) — 交戦(6交戦)ルールの変更
- **交戦中の狩り場へ新規敵グループが進入した場合、現在の交戦が終了するまで待機**し、次の交戦に参加(v0.5.0の即時参加を撤回)
- **敵グループが狩り場から離脱するために必要な交戦回数が従来の2倍**(6交戦→**12交戦**)
- ステージ7・8の神話ボスの耐性・免疫を減少

### v0.6.0 (Build 190, 2026/8/14) — 戦闘システム大改修 ★最重要
- **ダメージ属性を13種から9種に整理**(開発者ノートでは「従来より5種類少ない」と表記、つまり実質8種。公式本文と開発者ノートで数え方が異なる点に注意):
  - 刺突・斬撃・破砕(殴打) → **物理ダメージ**に統合
  - 電撃・雷鳴・酸・毒 → **自然ダメージ**に統合
  - 残る属性: 物理・火炎・冷気・自然・光輝・死霊・力場・精神
- **能力値システム圧縮**: 能力値**4ごとに修正値1**(旧式は2ごとに1=(能力値−10)/2)。代わりに**能力値修正値に応じてパーツのダイスダメージに割合ボーナス(%)**が適用(敵味方双方)。基本ダメージが高い高等級パーツほど能力値成長の恩恵が大きい
- **ターン単位の効果を秒単位に変更**: 施設・権能・バフなどは共通ターンではなく、**それぞれ独立した発動待機時間・持続時間(秒)**を持つ(事実上のリアルタイム化)
- **交戦開始時効果の発動タイミング変更**: 交戦開始直後ではなく、**そのキャラクターの最初の行動順が来た時**に発動
- 魔王昇級・昇天・様相システム、**無形パーツ**(旅内使い切り、元パーツより支配力が高い)、反復訓練を追加
- ［不壊の肉体］の脆弱が破砕→力場に変更
- Build 194: 解体時のパーツ生成確率が正常適用されていなかったバグを修正

### v0.6.1 (Build 198) — 修正値ボーナス方式の変更
- 能力修正値による「ダイス数ボーナス(%)」を「**ダイスダメージボーナス(%)**」に変更
- 作戦室・戦術マップ追加、施設改造を「すべての主要能力値修正値」ボーナスに変更、名誉レベル5=全主要能力値修正値+2、ワープゲート判定を知力判定に

### v0.6.2 (Build 199) — 昇格・覚醒の強化
- 変種研究システム追加(変種抽出回数を能力値上昇に再投資、種類単位で一括適用)
- **モンスター昇格の効果を2倍に増加、昇格の支配力ペナルティを削除**
- **覚醒段階の主要能力値範囲を0〜4から4〜8に変更**
- 「無敵の試練」を削除し「**攻勢の試練**」に置換。基本攻撃とメインパーツを常に決まった順番で使っていたバグ修正

### v0.6.3 (Build 205) — 安定化アップデート
- パーツ保管機能追加。能力の発動・対象指定・**能力値計算**の大量バグ修正(闘技場・背水の要塞・魔力の地脈等の施設効果が誤った数値を参照していた等)
- **移動中の敵は被弾しても停止せず移動を続ける**ように変更。混乱デバフの動作変更

### v0.7.0 (Build 208, 2026年10月) — 第2の大改修
- **新魔王3体追加: オステア、クインテッサ、ザリア**(Wikiの「追加予定」は実装済み)
- **権能システムを全面改編**(シューティング形式の操作、関連効果はすべて再調整)
- **モンスター「超越」機能**: 1等級モンスターの能力値を**10等級水準**まで強化、新固有特性・パーツを付与
- 新キャンペーン「**永遠の戦争**」(無限ステージ。経過で敵のダメージダイス・ボス能力値が増加、資源ボーナスは試練設定で最大2倍)
- **施設の耐久度システム変更**: 罠だけでなく**狩り場・設備も敵が耐久度を減らせる**ように
- **解体パーツ報酬改善**: 生成されなかったパーツのうち1つを追加獲得=最低1個保証。最大記憶段階では全パーツ同時獲得の可能性
- 戦闘中の行動ゲージ表示、試練+10段階挑戦、方舟パーツ除去機能、戦闘敗北後の再挑戦はノード選択へ戻る

### v0.7.2 (Build 217, 最新) — リアルタイム戦闘の調整
- グループ移動速度は**生存構成員全体の平均値**で計算
- 不死系列状態(［不死の肉体］等)の再付与では死亡タイミングが延長されない
- **反応行動の使用可能回数・クールダウンが交戦外でも更新**
- 女神の祝福［安息の祝福］:「次の交戦の主行動1回制限」→「周期的に味方の行動機会を1回消費」に効果改編
- 「リアルタイム戦闘への改編内容」のツールチップ一括更新 → **戦闘はリアルタイム制として運用されている**

### シミュレーションツールへの影響(重要)
- **v0.6.0より前の計算式記事(ailvgames第1・2回等)は旧仕様**: 能力値修正値(2ごとに1)、ダメージ属性13種、「1交戦=2ラウンド」等は v0.5.x までの仕様
- 現行(v0.6.0+)の要点: 修正値=能力値4ごとに1、ダイスダメージ%ボーナス、属性8〜9種、効果は秒単位の独立クールダウン、交戦開始時効果は初行動順時に発動
- Wikiのモンスター耐性表(斬撃/刺突/電撃等の旧属性表記)は統合後属性への変換が必要(例: スケルトンの刺突耐性→物理耐性、タイガーの毒耐性→自然耐性)

## 2. ステータス体系

### 2.1 等級(ランク)と種族
- モンスターの等級は1〜9。**習熟ボーナス = 等級−1**(最小1)。等級1,2=+1、3=+2、4=+3、5=+4、6=+5、7=+6、8=+7、9=+8。**魔王は等級7扱い(+6)**。
- 種族は3種: **野獣 / 精霊 / アンデッド**。気質(後述)は種族ごとに持ちうるものが異なる。
- 習熟ボーナスの適用: **命中ロールには常に加算**。DC・セーヴィングスローは「基準能力値が主能力値(＊マーク)の場合のみ」加算。

### 2.2 能力値
- 6能力値: 筋力 / 敏捷力 / 耐久力 / 知力 / 判断力 / 魅力。
- **能力修正値 = (能力値 − 10) / 2 (端数切り捨て)**。例: 14→+2、16→+3、18→+4、20→+5。
  - ⚠️ **v0.6.0で変更**: 能力値**4ごとに修正値1**(旧式の半分)に圧縮。代わりに能力値修正値に応じてダイスダメージに%ボーナス(v0.6.1でダイス数%→ダイスダメージ%に確定)。シミュレーションツールは対象バージョンで式を切り替えること。
- 主能力値(＊)はそのモンスターの最も秀でた能力値。敏捷力のみ先制力判定にも使われる。
- 個体値: 生成時にランダム+0〜1、覚醒(記憶)Lv最大で追加+4〜8(能力値)・+6d4(最大HP)、覚醒効果で主能力値+1、変種研究ボーナス。

### 2.3 支配力・グループ数
- 支配力は等級ごとに一律(v0.6.x Wiki値): 等級1=1, 2=2, 3=3, 4=4, 5=6, 6=9, 7=14, 8=20。
  - ※v0.3.2当時の攻略記事値(ランク1-5=同数値, 6=8, 7=22)から変更されている。ツールではWiki値を採用しつつ出典明記を推奨。
- 魔王は初期 最大支配力40 / グループ数2。狩り場に配置されたグループのモンスターのみ支配力を占有。保有・編成のみでは占有しない。
- 超過ペナルティ: 部下モンスターHP減少(超過/最大、上限75%減)、施設耐久度減少(同式)、ロールペナルティ(超過÷10切り捨て、命中/ダメージ/セーブ/能力判定)、魔王の能力値伝播が中断。
- モンスター配置可能数: 魔王の居室=魔王1+モンスター3(魔王昇級で最大7)、狩り場1つ=4体(前列2+後列2)。グループは1狩り場に1グループ。

### 2.4 昇格(モンスターの聖所)
同一モンスターを重ねて強化。段階1=1体、2=累計3体、3=累計7体(1,2,4と倍々)。最大HP・能力値が上昇。

## 3. 戦闘ルール (d20システム)

### 3.1 判定の基本式
- **命中ロール**: 1d20 + 能力修正値 + 習熟ボーナス ≥ 防御側のAC で命中(同値も命中)。
- **セーヴィングスロー**: 1d20 + 能力修正値(主能力値なら習熟ボーナスも) ≥ DC で成功(防御側が振る)。
- **先制力(イニシアチブ)**: 1d20 + 敏捷力修正値(+イニシアチブボーナス)。同値は敏捷力修正値が高い方が先。ラウンドごとに再ロール。
- 自然20=自動命中+クリティカル(ダメージダイス2回、修正値は1回のみ)。自然1=自動ミス(行動は消費)。
- **有利/不利**: d20を2回振り高/低い方を採用。命中・セーブ・能力判定に適用。
- **[範囲]タグ付き効果**: セーブ成功でも半分ダメージ(端数切り捨て)。

### 3.2 ダメージ計算
- ダメージ = ダイス + 能力修正値(基盤能力値) **+ 魔王の能力値伝播**(魔王の同能力値修正値が味方のダメージロールに加算。全モンスター・全施設に有効)。⚠️ v0.5.0以降、**モンスターと魔王の修正値のうち低い方は半分のみ適用**。⚠️ v0.6.0以降は修正値に加えて**ダイスダメージ%ボーナス**が乗る(詳細比率は未確認)。
- ダメージタイプ(旧・v0.5.xまでの13種): 物理(斬撃/刺突/殴打)、属性(火炎/冷気/電撃/雷鳴/酸/毒)、魔法(光輝/死霊/力場/精神)。⚠️ **v0.6.0で9種(実質8種)に統合**: 斬撃・刺突・殴打→物理、電撃・雷鳴・酸・毒→自然。現行属性: 物理/火炎/冷気/自然/光輝/死霊/力場/精神。複数タイプ攻撃は命中1回・タイプごとに別処理。
- 耐性=1/2、脆弱性=2倍、免疫=0。**耐性は1攻撃に1回のみ適用**(複数耐性でも1/4にならない)。耐性と脆弱性の併持は相殺。適用順: ロール→追加ダメージ合算→脆弱性→耐性→免疫。
- 一時的HP: 最大HPとは別枠、ダメージを先に消費、重複せず最大値で置換、回復では補充されない。

### 3.3 交戦・ラウンド・ターン
- 敵グループが狩り場(または魔王の処所)に進入すると交戦開始。全員が先制力ロール→行動順に主要行動。
- **1交戦 = 通常2ラウンド**。主要行動(Mパーツ等)を2つ持つキャラのみラウンド2でもう一方を使用。ラウンド1で使う主行動はランダム選択。
- 主要行動: 自分のターンに1回、交戦中は使い切り(交戦終了で回復)。交戦開始時能力は「交戦フェーズが1巡するたび」再発動。
- 反応行動: トリガー条件で発動、**1交戦に1回**。
- 持続効果: 常時発動のパッシブ。
- **6交戦ルール**: 敵は6回交戦すると強制的に次の部屋へ移動する(スタン等で封殺しても突破される)。⚠️ **v0.5.4で離脱に必要な交戦回数が2倍(6→12交戦)に変更**。⚠️ v0.5.4以降、交戦中の狩り場への新規敵グループは現在の交戦終了まで待機してから次の交戦に参加。※開発者掲示板情報では今後「交戦は片方の陣営が全滅するまで続く」仕様への変更が告知済み。
- **交戦開始時効果**: 旧仕様では交戦開始直後(かつ1巡ごとに再発動とする解説もあり)。⚠️ **v0.6.0で「そのキャラクターの最初の行動順が来た時」に発動するように変更**。
- ターン(砂時計)は時間経過で進み、1交戦に約2ターン。罠・権能のクールダウンはターン単位。⚠️ **v0.6.0でターン単位の効果はすべて秒単位の独立した発動待機時間・持続時間に変更**(事実上のリアルタイム戦闘化。v0.7.0で行動ゲージ表示、v0.7.2で移動・反応行動・不死の判定がリアルタイム仕様に調整)。

### 3.4 グループ戦・ターゲット選択
- グループ=前列2+後列2の最大4体。前列は近接攻撃を受ける盾、後列は守られやすい位置。
- **射程1=敵前列まで、射程2=敵前列+後列**。射程はスキル側の属性で、攻撃者の位置には依存しない。敵前列が全滅すると後列が前列扱い(射程1でも届く)。
- ターゲットは射程内の有効な敵から**ランダム**選択。挑発状態は挑発元(射程内なら)を優先。透明化は通常候補外(攻撃者の判断力判定 vs 対象の敏捷力判定で成功すれば候補化、唯一の対象なら自動ターゲット)。

### 3.5 罠の解除
- 敵グループが罠マス進入時に敵が敏捷力判定、**DC12以上で解除成功**→罠の耐久度−1。失敗時は罠が発動。耐久度0で破壊。
- 列罠(横列/縦列)は同一列の全マスに影響し、味方を巻き込む([危険]系)。

## 4. 能力(アビリティ)とパーツ体系 — シミュツールの核

### 4.1 能力スロット構成
各キャラクター(魔王・モンスター)は5スロット:
1. **基本攻撃**(固有)
2. **固有特性 B**(固有)
3. **主要パーツ M**(装備可・必須1つ)
4. **補助パーツ S1**
5. **補助パーツ S2**

- パーツは**別種・魔王/モンスター間でも装備自由**。
- 補助パーツのS1/S2は**装備枠共通**。S1×S1、S2×S2も可。**同一パーツ2枚は1枚分のみ機能**。
- パーツには固有のステータス補正(HP/AC/DC/init/能力値)と耐性が設定され、装備先のステータスへ反映。等級表記上の支配力もパーツごとに設定(例: ヒュドラM=+3.8, S1/S2=+1.9)。

### 4.2 パーツ入手
- モンスター解体(安息所): ①装備中パーツからランダム1つ + ②その種族由来パーツ(M: 記憶Lv28以上で24%、S1/S2合計50%、MとSは独立判定、S1とS2は同時不出)。⚠️ v0.5.0で確率大幅増加(M: 基本18%/最大48%、S: 基本30%/最大90%)。⚠️ v0.7.0で**最低1個保証**(生成されなかったパーツのうち1つを追加)+最大記憶段階では全パーツ同時獲得の可能性。
- 商人購入(5等級まで。6等級は超々レア)、イベント産(キメラ培養室等)、収集家のルーペ(ドロップ)。**7等級以上のパーツは解体のみ**。
- v0.6.0で**無形パーツ**追加(9等級まで旅中ドロップ、方舟引き継ぎ不可)。
- パーツ抽出で対象モンスターは死亡。方舟刻印個体からは抽出不可。

### 4.3 主要パーツ(M)のデータ形式(例)
ヒュドラ(等級7):
- M-猛毒牙の大剣: 補正 筋力+2。前列 4d10 斬撃(筋力修正値) + 2d12 酸(耐久力修正値)。タグ: 主行動/筋力基準/近接/筋力命中ロール/範囲
- S1-ヒドラの鱗: 補正 耐久力+2。前列 3d10 酸(耐久力修正値)。タグ: 反応行動/耐久力基準/範囲/敏捷力セーブ(DC16+耐久力修正値)
- S2-再生する頭: 補正 HP+20。2d12 回復(耐久力修正値)。交戦終了時「蛇の頭」1スタック+回復。

## 7. 魔王仕様

- 魔王3体(初期): **レア**(野獣/筋力・耐久型)、**アウラ**(精霊)、**デスポニア**(アンデッド)。⚠️ **v0.7.0でオステア・クインテッサ・ザリアの3体が実装済み**(計6体。様相: ザリア=狂気/血の刻印、クインテッサ=三元結晶学(火炎・冷気・電撃の結晶)、オステア=遺骨)。
- レア例: HP105, AC10, 筋16/敏10/耐16/知4/判10/魅10。基本攻撃 2d8+3斬撃(筋力命中+9)。固有特性「獅子王の心臓」(侵攻開始時勇猛5スタック)。専用パーツM/S1/S2、専用遺物4種。
- **権能**のランク: 基本(ターン周期) / 補助(ターン周期) / 特殊(戦闘1回) / 究極(数日周期)。⚠️ **v0.7.0で権能システムを全面改編**(シューティング形式の操作、全効果を再調整、基本DC12統一はv0.5.0〜)。v0.7.0以前の権能データは旧仕様。
- **能力値伝播**: ダメージロールに基盤能力値の魔王修正値を加算。モンスター最大HP += 魔王の耐久力修正値×等級。罠の耐久度 += 魔王の耐久力修正値÷2(切り捨て)。⚠️ v0.5.0以降、**モンスターと魔王の修正値のうち低い方は半分のみ適用**。
- **魔王の処所**: 全敵グループが入場可。敵グループと1組ずつ順次交戦(未交戦グループからランダム選択)を全グループ反復。
- 魔王昇級で最大支配力・グループ数・配置モンスター数が増加。

## 11. シミュレーションツール開発への要件メモ

### 11.1 必要データモデル
1. **モンスター定義**: 等級/種族/HP/AC/能力値6種/主能力値/耐性/脆弱性/基本攻撃/固有特性
2. **パーツ定義**: 名前/元モンスター/枠(M,S1,S2)/ステータス補正/効果文(行動種別・基準能力値・ダイス・射程・命中/セーブ・DC式・範囲・持続)/支配力コスト
3. **気質定義**: 名前/効果/種族制限/レアリティ
4. **魔王定義**: 能力値/基本攻撃/固有特性/権能/専用パーツ/専用遺物
5. **施設定義**: カテゴリ/効果/範囲タグ/安全危険/基準能力値/クールダウン/必要施設(合成)
6. **状態異常定義**: 効果/持続/スタック仕様
7. **敵(勇者)定義**: 等級別基礎値+試練補正(別途データ収集が必要)

### 11.2 シミュレーションコアの計算式(実装済み可能なもの)
⚠️ 以下はv0.3.x〜v0.5.xベースの式。v0.6.0以降は能力値修正値(4ごとに1)・ダイスダメージ%ボーナス・属性統合(8種)・秒単位クールダウンに置き換えること(§0参照)。**ツールはバージョン切替可能な設計を推奨。**
- 命中: 1d20 + 能力修正値 + 習熟ボーナス(等級-1) vs AC(基礎8+補正)
- ダメージ: Σダイス + 能力修正値 + 魔王伝播 → 脆弱→耐性→免疫の順で適用
- セーブ: 1d20 + 能力修正値(+主能力値なら習熟) vs DC(基本値+修正値+主能力値なら習熟)
- 最大HP: 基礎 + 魔王耐久修正値×等級 + 個体値
- 交戦ループ: 先制(1d20+敏捷修正)→主要行動(1交戦2ラウンド、反応1回/交戦)→6交戦で部屋移動
- 支配力: Σ(等級別コスト)+パーツ支配力 ≤ 最大、超過時ペナルティ計算
